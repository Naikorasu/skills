# Skills

[![skills.sh](https://skills.sh/b/naikorasu/skills)](https://skills.sh/naikorasu/skills)

This repository contains agent skills that can be installed with `npx skills add`.

## Installation

Install either skill individually:

```bash
npx skills add https://github.com/naikorasu/skills --skill create-infographic-document
npx skills add https://github.com/naikorasu/skills --skill create-wireframe
```

## Skills

| Skill | Description |
|-------|-------------|
| [create-infographic-document](./skills/create-infographic-document/SKILL.md) | Converts complex raw information into visually intuitive, structured Markdown documents with Mermaid diagrams, tables, callouts, and shields.io badges. |
| [create-wireframe](./skills/create-wireframe/SKILL.md) | This skill creates and renders UI wireframes from Markdown with the wiremd CLI without requiring Claude Code. |
