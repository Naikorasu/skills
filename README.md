# Skills

[![skills.sh](https://skills.sh/b/naikorasu/skills)](https://skills.sh/naikorasu/skills)

Agent skills collection. Designed to be installed via `npx skills add`.

## Installation

```bash
# Install all skills
npx skills add naikorasu/skills

# Install a specific skill
npx skills add naikorasu/skills --skill create-infographic-document
```

Or install directly from GitHub URL:

```bash
npx skills add https://github.com/naikorasu/skills --skill create-infographic-document
```

## Skills

| Skill | Description |
|-------|-------------|
| [create-infographic-document](./skills/create-infographic-document/SKILL.md) | Converts complex raw information into visually intuitive, structured Markdown documents with Mermaid diagrams, tables, callouts, and shields.io badges |
